# CS 61A Resources

Past CS 61A exams, solutions, and study guides. To browse them, visit the
Resources page of a course website:

- [CS 61A Fall 2026 Resources](https://cs61a.org/fa26/resources/)
- [Data C88C Fall 2026 Resources](https://c88c.org/fa26/resources/)

## File URLs

- Exams: `https://cs61a.org/resources/<semester>/<mt1|mt2|final>/61a-<semester>-<exam>.pdf`,
  e.g. [fa25/mt1/61a-fa25-mt1.pdf](fa25/mt1/61a-fa25-mt1.pdf)
- Solutions: the same path ending in `_sol.pdf`, e.g.
  [fa25/mt1/61a-fa25-mt1_sol.pdf](fa25/mt1/61a-fa25-mt1_sol.pdf)
- Study guides: `https://cs61a.org/resources/guides/`
- Exam indexes: `https://cs61a.org/resources/_exams/` (`exam_files.json`,
  `in_scope.json`, and `exam_problems_{mt1,mt2,final}.json`)

Summer offerings with a single midterm name it `61a-<semester>-midterm.pdf`.
A few exams are zip archives instead of PDFs.
