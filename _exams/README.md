# Exam problem indexes

The exam indexes are split by exam type and sorted newest first:

- [`exam_problems_mt1.json`](exam_problems_mt1.json)
- [`exam_problems_mt2.json`](exam_problems_mt2.json)
- [`exam_problems_final.json`](exam_problems_final.json)

Exams use compact labels such as `fa25-mt1`, `sp26-mt2`, and `su26-final`.
Each exam includes its solution playlist or video links in `playlist_links`.
Each problem includes only its number, title, and topic tags. Problems without
a source topic tag are retained as `UNTAGGED`.
